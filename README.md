# numpy-problems
I had learned basic Python before, so many concepts felt somewhat familiar. But when I started NumPy, it honestly felt like learning something completely new. Arrays, vectorized operations, reshaping, broadcasting, filtering... everything worked differently from regular Python.



Over the last few days, I focused on learning NumPy and today I completed 8 practice projects to strengthen my understanding.



Projects I built:

• Marks Analysis (Mean, Max, Min, Standard Deviation)

• Even/Odd Number Filtering

• Array Reshaping (2D & 3D Arrays)

• Broadcasting Operations

• Student Result Analysis System

• Temperature Analysis System

• Matrix Operations

• Data Normalization (0 to 1 Scaling)



The Student Result System and Temperature Analysis projects were especially interesting because they felt closer to working with actual data instead of just solving programming exercises.



A few weeks ago, terms like broadcasting, reshaping, and normalization sounded intimidating. Now I'm able to use them in programs and understand what they're doing behind the scenes. Small progress, but definitely feels like another step forward.



On to the next topic.
